# Malek Mahmoud — SalahNest Homepage

A lightweight bilingual (English/Arabic) personal homepage introducing Malek Mahmoud, the SalahNest app, and the Eduverse Student Portal Redesign.

## Site files

The deployable static site is in `site/`. It contains only the page and assets it loads:

- `index.html` — semantic page structure and bilingual content hooks
- `styles.css` — responsive cream-and-forest visual identity, including RTL layout
- `script.js` — language switch and mobile navigation
- `salahnest-mark.png` — the existing official SalahNest app icon
- `eduverse-redesign.webp` — lightweight conversion of the actual public Eduverse sign-in / landing screenshot

No build step, external font request, analytics, or site backend is required.

## Projects

The SalahNest links remain official and unchanged:

- https://malekmahmouda.github.io/salahnest/
- https://github.com/MalekMahmouda/salahnest

The Eduverse project is the responsive Student Portal Redesign at https://eduverse-redesign.vercel.app. The portfolio describes it at a restrained, high level: it organizes coursework, schedules, lessons, materials, and live-class links with English/Arabic and RTL support. Account-specific records remain behind sign-in; the public screenshot contains no student data. The screenshot and caption identify the actual public sign-in / landing view, not a concept mockup.

## Local preview

Open `site/index.html` directly in a browser, or serve `site/` with any static HTTP server.
