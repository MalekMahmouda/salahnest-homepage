# Malek Mahmoud — Portfolio

A bilingual English/Arabic portfolio for Malek Mahmoud, introducing two independent projects: SalahNest and the Eduverse Student Portal Redesign.

**GitHub Pages:** https://malekmahmouda.github.io/salahnest-homepage/

## Site files

The static site is served from the repository root:

- `index.html` — semantic page structure and bilingual content hooks
- `styles.css` — responsive visual design, RTL layout, and reduced-motion-aware transitions
- `script.js` — language switching, mobile navigation, and optional scroll reveals
- `salahnest-mark.png` — the existing SalahNest app icon
- `eduverse-redesign.webp` — the actual public Eduverse sign-in / landing screenshot, with no student-specific records

No build step, external font request, analytics, or site backend is required.

## Projects

SalahNest is a companion for prayer times, Quran, Qibla, dhikr, and related everyday worship tools:

- https://malekmahmouda.github.io/salahnest/
- https://github.com/MalekMahmouda/salahnest

The Eduverse Student Portal Redesign is available at https://eduverse-redesign.vercel.app. The portfolio describes it at a high level: it organizes coursework, schedules, lessons, materials, and live-class links in a responsive bilingual interface. Student-specific records remain behind sign-in; the public screenshot contains no student data.

The public profile shows the age as “13 years old” (or its Arabic equivalent) only; it does not display a birth date.
